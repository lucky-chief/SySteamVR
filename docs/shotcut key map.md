# 快捷键说明（按键提示图用）

适用：`shiyan_nakedmonitor` 驱动，`display_mode = direct`。交互模式有
**vr_sim**（默认）与 **natural_mouse** 两种，按 `G` 可运行时切换。

> 所有按键都由驱动的 raw input 全局捕获（不依赖哪个窗口有焦点）。

---

## 1. 全局热键（两种模式都可用）

| 键 | 功能 |
|---|---|
| `V` | 显示 / 隐藏按键提示图 |
| `A` / `D` 或 `←` / `→` | **仅在提示图可见时**：上一页 / 下一页（循环）；此时这几个键不参与移动/摇杆 |
| `H` | 显示 / 隐藏系统鼠标指针（只作用于 direct mode 的输出窗口） |
| `G` | 切换交互模式：vr_sim ⇄ natural_mouse |

---

## 2. vr_sim 模式

默认激活目标是**头**。同一时刻只有一个激活目标，键盘/鼠标操作它。

### 目标选择

| 键 | 功能 |
|---|---|
| `1` | 激活目标 = **头** |
| `2` | 激活目标 = **左手** |
| `3` | 激活目标 = **右手** |
| `Tab` | 循环切换目标（头 → 左手 → 右手 → 头） |

### 瞄准

| 操作 | 功能 |
|---|---|
| 移动鼠标 | 转动**激活目标**朝向（增量、无左右上限、上下 ±75°）；目标是头时转头，目标是手时转手 |
| 按住鼠标中键 | 临时转头（即使当前目标是手） |
| `F` | 切换“鼠标平移模式”：开启后移动鼠标 = 横移 / 升降激活目标（不转向） |
| `Z` | 双手重置到头前（距离/高度可配置），朝向与头部一致 |

### 移动（沿头部朝向的水平面；`Shift` 按住 = 3× 速度）

| 键 | 功能 |
|---|---|
| `W` / `S` | 激活目标前进 / 后退 |
| `A` / `D` | 激活目标左移 / 右移 |
| `Q` / `E` | 激活目标下降 / 上升 |
| `Shift` | 移动速度 ×3 |
| 鼠标滚轮 | 激活目标是**手**时：该手前进/后退（0.1 m/格）；目标是头时：无动作 |

### 按键（发给**激活手**）

| 键 | 功能 |
|---|---|
| 鼠标左键 | 扳机（trigger） |
| 鼠标右键 | 握持（grip / squeeze） |
| `X` | 面板主键（左手 `X`、右手 `A`） |
| `C` | 面板副键（左手 `Y`、右手 `B`） |
| `R` | 摇杆按下 |
| 方向键 `↑↓←→` | 摇杆（X / Y） |
| `M` | 系统菜单（application menu），不受激活目标限制（头目标时发给主手） |

> 激活目标是**头**时，手部按键无接收者（`M` 仍发给主手）。

---

## 3. natural_mouse 模式

鼠标是**面板上的指针**：两只手的瞄准都沿“眼睛 → 光标落点”的射线。

| 操作 | 功能 |
|---|---|
| 移动鼠标 | 移动面板指针（不转向） |
| 按住鼠标中键 | 临时转头 |
| `W` / `S` / `A` / `D` / `Q` / `E` | 移动**头部**（视空间，`Shift` = 3×） |
| `F` | 鼠标平移模式（鼠标 = 头部横移 / 升降） |
| 鼠标滚轮 | 摇杆 Y 轴短脉冲（模拟前进/后退） |
| 左键 / 右键 / `X` / `C` / `R` / 方向键 / `M` | 全部发给**主手**（`primary_hand`，默认右手） |
| `1` / `2` / `3` / `Tab` | 无作用（目标切换只在 vr_sim 生效） |
| `Z` | 重置双手（此模式下控制器姿态由射线决定，基本看不到效果） |

> 已知简化：OpenVR 每个设备只发布一个姿态，所以 natural_mouse 下两只手会落在同一条鼠标射线上。

---

## 4. 手柄（XInput → 虚拟左右手）

物理手柄由驱动用 XInput 轮询，映射到与键鼠相同的虚拟左右手。手柄**不提供**
目标切换，目标仍用键盘 `Tab` / `1` / `2` / `3` 选择。

| 手柄输入 | 功能 |
|---|---|
| 左摇杆 | 移动激活目标（= `W`/`A`/`S`/`D`，模拟量） |
| 右摇杆 | 转动激活目标（= 移动鼠标；vr_sim 下转头/转手，natural_mouse 下转头） |
| `LT` / `RT` | 扳机 / 握持（激活手，模拟量） |
| `A` / `B` | 面板主键 / 副键（= `X` / `C`） |
| `X` | 系统菜单（= `M`） |
| `Y` | 显示 / 隐藏提示图（= `V`） |
| `Back` | 双手重置（= `Z`） |
| `Start` | 切换 vr_sim ⇄ natural_mouse（= `G`） |
| `LB` | 移动速度 ×3（= `Shift`） |
| `RB` / 右摇杆按下 | 摇杆按下（= `R`） |
| 十字键 | 摇杆 X / Y（方向键） |
| 手柄震动 | 应用的触觉反馈（`/output/haptic`）→ `XInputSetState` |

设置（`shiyan_nakedmonitor_gamepad`）：`enabled`、`slot`（-1 = 第一个连接的手柄）、
`deadzone`、`rumble`、`rumble_gain`；摇杆转向速度在
`shiyan_nakedmonitor_controller`：`sim_stick_look_yaw` / `sim_stick_look_pitch`
（度/秒，默认 130 / 80）。

> 使用前需关闭 SteamVR 的 **Steam Input**，并在 `steamvr.vrsettings` 里设置
> `"driver_gamepad": { "enable": false }`（否则内置 gamepad 驱动也会读取手柄）。

## 5. 按键 → OpenVR 输入组件

用于核对应用里的绑定：

| 输入 | 组件路径 |
|---|---|
| 鼠标左键 | `/input/trigger/value` + `/input/trigger/click` |
| 鼠标右键 | `/input/grip/value` + `/input/grip/click` |
| 左手 `X` / `Y` | `/input/x/click` / `/input/y/click` |
| 右手 `A` / `B` | `/input/a/click` / `/input/b/click` |
| `M` | `/input/application_menu/click` |
| 方向键 | `/input/joystick/x`、`/input/joystick/y` |
| `R` | `/input/joystick/click` |
| 震动反馈 | `/output/haptic` |

---

## 6. 提示图相关设置

`shiyan_nakedmonitor_help`：

| 键 | 说明 |
|---|---|
| `enabled` | 总开关 |
| `images` | 逗号分隔的 PNG 文件名（每页一张），放在 `resources/images/` |
| `width_ratio` | 图片宽度占**半屏宽度**的比例（默认 0.9） |

显示规则：每页在**左右两个半屏各画一次**，水平/垂直居中、保持宽高比、不拉伸；
宽度为半屏的 `width_ratio`，若高度超出则按高度等比回缩。支持 PNG 透明通道。

---

## 7. 建议的提示图分页

1. **全局**：`V` / `A D ← →`（翻页）/ `H` / `G`
2. **vr_sim 目标与瞄准**：`1` `2` `3` `Tab`、鼠标瞄准、中键转头、`F`、`Z`
3. **vr_sim 移动与按键**：`WASD/QE`、`Shift`、滚轮、左/右键、`X` `C` `R`、方向键、`M`
4. **natural_mouse**：指针、中键转头、`WASD/QE`、滚轮、按键发主手、`1/2/3/Tab` 无效
5. **手柄**：`gamepad_help.png`（左/右摇杆、扳机、A/B/X/Y、Back/Start、十字键、震动）

---

## 8. 其它

- 本驱动没有 `ESC`、`Ctrl+Alt+*` 等组合热键。
- `Z` 的重置距离/高度：`hand_reset_distance_m`（默认 0.2）、`hand_reset_height_offset_m`（默认 -0.3）。
- 手部转向灵敏度：`sim_hand_look`（默认 1.0）；头部：`sim_head_look`。
